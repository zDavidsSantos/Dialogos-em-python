Python (linguagem de programação)

Última modificação: 10 de outubro de 2025 — Leitura: 7 min
Python
Paradigmas: Programação orientada a objetos, imperativa, funcional
Primeira versão: 1991
Autor: Guido van Rossum
Saiba mais

Python é uma linguagem de programação de alto nível, interpretada, com tipagem dinâmica e forte ênfase em legibilidade e produtividade. É amplamente usada em desenvolvimento web, ciência de dados, automação, entre outros.

História

Python foi criado por Guido van Rossum no final da década de 1980 e lançado em 1991. Desde então, evoluiu através de contribuições da comunidade, com grandes marcos como as versões 2.x e a transição para 3.x, que introduziu mudanças incompatíveis para melhorar a linguagem a longo prazo.

Características

  • Sintaxe clara e legível.
  • Ampla biblioteca padrão.
  • Grande ecossistema de pacotes (PyPI).
  • Tipagem dinâmica e gerenciamento automático de memória.

Exemplo de código

Exemplo simples em Python:

# Imprime os números pares de 0 a 10
for i in range(11):
        if i % 2 == 0:
                print(i)
